🦫 Privacy Policy

Capybara River Survival · Terakhir diperbarui: 5 Oktober 2026

1. Pendahuluan

Kebijakan Privasi ini menjelaskan bagaimana aplikasi Capybara River Survival ("Aplikasi", "kami") menangani informasi Anda. Aplikasi ini adalah game survival tanpa akhir untuk perangkat Apple, dibuat oleh PAI Team.

2. Data yang Kami Kumpulkan

Kami tidak mengumpulkan data pribadi apa pun. Aplikasi ini tidak meminta akun, nama, email, lokasi, kontak, foto, maupun data sensitif lainnya.

Data yang tersimpan hanya berupa skor tertinggi (high score) dan pengaturan game, yang disimpan secara lokal di perangkat Anda dan tidak dikirim ke server mana pun.

3. Pelacakan, Analitik, dan Iklan

  • Aplikasi tidak melacak pengguna antar aplikasi atau situs web lain.
  • Aplikasi tidak menggunakan SDK analitik atau iklan pihak ketiga.
  • Aplikasi tidak menjual atau membagikan data kepada pihak ketiga.

4. Haptic Feedback dan Suara

Aplikasi menggunakan haptic feedback dan efek suara untuk pengalaman bermain. Fitur ini berjalan sepenuhnya di perangkat dan tidak mengumpulkan data apa pun.

5. Privasi Anak

Aplikasi tidak secara sadar mengumpulkan informasi pribadi dari siapa pun, termasuk anak-anak. Karena tidak ada data pribadi yang dikumpulkan, Aplikasi aman dimainkan oleh semua usia sesuai peringkat usia di App Store.

6. Keamanan dan Penyimpanan Data

Data lokal (skor tertinggi) berada di penyimpanan aplikasi pada perangkat Anda. Menghapus Aplikasi akan menghapus data tersebut.

7. Perubahan Kebijakan

Kami dapat memperbarui Kebijakan Privasi ini sewaktu-waktu. Perubahan akan ditampilkan di halaman ini dengan tanggal pembaruan yang baru.
